# CINEVISION

**See Beyond the Screen.**

---

## Vision

CINEVISION is an immersive cinema discovery and discussion platform that transforms
how film enthusiasts explore, analyze, and talk about movies. It combines a premium
dark-cinema aesthetic with interactive 3D environments, scroll-driven storytelling,
and thoughtful community features.

The project follows a **design-first** approach: the frontend is built with mock data
before backend integration.

## Development Rules

This project enforces strict development protocols:

- **No automatic commits.** Every commit requires explicit approval.
- **No blind staging.** Files are reviewed and selectively staged.
- **No force-pushes.** History is never rewritten without approval.
- **No destructive commands** without explanation and approval.
- **No secrets in commits.** Environment files and credentials are always excluded.
- **Inspect before modifying.** Existing files are read and understood before changes.
- **Verify before committing.** Build, lint, and test checks run before every commit.
- **Design-first approach.** Frontend with mock data before backend integration.
- **Incremental progress.** One polished screen at a time.
